# Code Quest 2

**When:** Saturday 1 August 2026
**Where:** in person, Manchester
**Recorded:** 16 August 2026, from the event site, the footage, and the builds themselves

---

## Who

**Kids, six competing:** Elsie, Hannah, Sophia, Theodore, Ezekiel, Arthur. Emma present, too young to compete.
**Judge:** Grandma, on a published scorecard.
**Run by:** Bolaji.

**Teams:** Triad Labs and Pixel Power.

## The shape

One day, in one room, rather than two weeks across three time zones. That is the single biggest change from Code Quest 1.

Six builds that did not exist that morning. Every child presented their own to the family.

## As it happened

**10:00, before a word was said,** the Awakening films played. One per child, drawn from a photograph taken the week before, each cousin transformed and taking up the crest.

**Morning:** the build.

**Afternoon:** the Telling. Every child stood up and explained what they had made. Four of the ten marks on the scorecard were for the explaining, not the building.

**Close:** Grandma judged publicly and named something specific about every single child.

## The verdict

**A tie.** Triad Labs built the stronger thing, Pixel Power explained theirs better, and neither was placed above the other. Both teams took first.

**Unverified:** the prize amount. The archive page records twenty pounds per team; an earlier note recorded seventy-five pounds in payouts. Needs confirming.

## More than one medium, unplanned

Code Quest 2 is usually described as the one where they built games. That undersells it. The structure of the day meant the kids produced games and apps, but also videos, presentation slides and music.

Nobody designed a multi-medium event. It expanded on its own, four months before anyone articulated the argument that coding is only the first medium.

## What changed between Code Quest 1 and 2

| | Code Quest 1 | Code Quest 2 |
|---|---|---|
| Format | Virtual, three cities | In person, one room |
| Duration | Two weeks of self-directed work | One day |
| Built | Quiz games, to a spec | Whatever each child wanted |
| Judged by | The parents, five criteria | Grandma, published ten-mark scorecard |
| Recognition | Seven badges | Seven named awards |
| Ceremony | None | The Awakening films, the Telling |
| Result | A verdict, unrecorded | A tie, on the record |
| Afterwards | Code Quest 2 proposed on the night | Kids kept building, unasked |
