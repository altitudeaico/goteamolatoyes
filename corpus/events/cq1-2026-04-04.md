# Code Quest 1

**When:** kickoff Sunday 22 March 2026, hackathon Saturday 4 April 2026, 6:30pm
**Where:** virtual, Google Meet, across three houses: New York, Middleton, Gravesend
**Called at the time:** Olatoye Academy Coding Bootcamp
**Recorded:** 16 August 2026, from the kickoff transcript and the recap pages built at the time

---

## Who

**Kids, six:** Elsie, Hannah, Sophia, Theodore, Ezekiel, Arthur.
**Also present:** Emma, age four, too young to compete.
**Adults:** Bolaji ran it. Gbenga co-hosted the kickoff. Invited across the households: Shade, Funmi, Ayo, Paulina, May.

**Teams, chosen by the kids themselves in about thirty seconds.** Elsie proposed girls versus boys, three on three.

- **Girl Power:** Elsie, Hannah, Sophia
- **Tech Bros:** Theodore, Ezekiel, Arthur

## The shape

A kickoff session, then two weeks of self-directed work in their own time across three time zones, then a demo night.

**Deliverables:** a personal webpage and an interactive quiz game.
**Tools:** Claude for building, GitHub for hosting, Supabase for the database.
**Support:** a Code Quest app with seven levels, points, a leaderboard and a parents' view.
**Prize:** bragging rights.

## The kickoff, 22 March

Roughly seventy minutes. Opened with a whisper-scream competition, which Arthur won on the grounds that nobody could hear him.

The teaching frame was imagination as a superpower, using Green Lantern, Iron Man, Riri Williams and Shuri. Then AI as the tool that turns description into a built thing. The line repeated through the session: *if you can think it and describe it clearly, AI can help you build it.* No coding knowledge required, only imagination and words.

Everyone defined AI and then a prompt in their own words. Gbenga's definition landed: a prompt is talking to the AI.

The hackathon date nearly moved because Elsie had a friend's birthday party on the 4th. She checked, reported that it finished at four, and confirmed she would make 6:30.

## The build fortnight

**Tech Bros, 1 April.** Ezekiel showed a Race Engineer Simulator he had built solo, in which you run an F1 team. Everything worked except the music, because Claude's preview cannot play audio. The team then decided not to build three separate quizzes but to combine their best ideas into one, described at the time as assembling a superhero team. Ezekiel emailed his code to Theodore and Arthur. They set up a shared account, Tech Bros 3, tried to push, and GitHub refused a password. Ezekiel worked out it needed a Personal Access Token, created one, fixed a typo in the address, and got it live.

**Girl Power, 2 April, two sessions in one day.** In the morning session, 9:17am, Elsie set up GitHub and Supabase from scratch with Bolaji. The team name was decided before a line of code was written. She used Claude to design the look: pastel, glitter, sparkles, butterflies, confetti on a correct answer. Claude's first attempt came back too dark and she rejected it and specified exactly what to change. Questions were written about things she actually knows: fashion, art, makeup, cheerleading. An evening session at 5:55pm brought all three girls together.

Across the fortnight the slideshow built for the night recorded sixteen bugs fixed.

## The night, 4 April

Started around 6pm. Four apps demoed, all working, all live on the internet.

| App | Made by | Notes |
|---|---|---|
| Ezekiel's F1 Quiz | Ezekiel, solo | 20 questions, animated race track, qualifying grid scoring |
| Tech Bros Quiz | Tech Bros | Multiplayer. Tech, F1 and Ninjago. Game code BROS |
| Elsie's Girl Power Quiz | Elsie | Fashion, art, makeup, cheerleading. Game code GIRL |
| Cousin Quiz | Hannah and Sophia, independently | Game code QUIZ |

**Judged by the parents** on five criteria: design, questions, gameplay, features, presentation.

**A bug happened live.** Hannah and Sophia's Cousin Quiz froze mid-demo, questions would not advance. It was framed on the night as what happens in real software, which is true and was the right call.

Each child answered one question: what do you know now that you did not know two weeks ago. The answers were how to prompt AI clearly, what a database actually is, how to put something on the internet, and, from Elsie, confidence and clear presentation.

> "You need confidence and to present clearly." — Elsie, 4 April 2026

**Unverified:** the recap records that the parents deliberated and a verdict was reached, but does not name the winning team. Either it was left open or it was never written down. Worth confirming with someone who was there.

## What was decided on the night

Code Quest 2 was proposed before the night ended, with a stated ambition: harder challenges, and apps that solve real problems rather than quizzes. That is what August delivered.

The pattern of proposing the next event at the end of the current one starts here.
