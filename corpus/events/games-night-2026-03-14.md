# Family games night

**When:** Saturday 14 March 2026, evening UK, afternoon New York
**Where:** virtual, Google Meet, four households
**Recorded:** 16 August 2026, from the meeting transcript

This is where Code Quest comes from. It was recorded eight days before the Code Quest 1 kickoff and it explains everything that followed.

---

## What it was

A family quiz night, run by Bolaji, built with Claude. Not the first: the transcript refers to a previous quiz and to a Christmas quiz that Middleton won in 2025, so there is a family quiz series running before this.

Teams were the four households: New York, Middleton, Graves End, Radlett. Three games were played. New York won all three.

The quiz was personalised, mixing family facts with Easter Bible trivia. It fell the day before Mother's Day, and the session paused so everyone could say something to the mothers. Elsie spoke for her mum, her aunties and her grandmother.

## The kids were already building

The single most important fact in this file.

> "My dad asked me to write down everybody in this family and what they liked. Hannah did the parents and the grandparents and I did the grandchildren. And then I sent it to my mom, and my mom sent it to my dad, and now my dad's put it into Claude, and the questions will be about what they like."
> **Elsie**, 14 March 2026

Elsie and Hannah researched and wrote the source material for the quiz. Before Code Quest existed, before anyone used the word hackathon, two children were already contributing to a build. The room applauded them for it.

## Then it broke, repeatedly

- **Arthur reported the first bug.** He answered every question correctly and finished at the bottom of the leaderboard
- **Gbenga reported the second.** None of the questions were about him
- **Aunty Lina took over as quiz master for game three and it failed.** The game froze and showed different questions to the host than to the players. Bolaji had to resume hosting
- Scores appeared to double where two people from one household joined
- The leaderboard did not display properly after a game ended

## The invitation came out of the failure

> "If you want to help me with the quiz next time, anybody who wants to help, I can show you how to create the code of this using Claude and all this kind of stuff. Maybe we can have a session where we all get together and we can work out what a cool quiz would be and any features that are missing. Would you guys be up for that?"
> **Bolaji**, 14 March 2026

> "Yes, definitely."
> **Aunty Lina**

Arthur was invited directly: help me fix it for the next one, so we can fix the bugs together.

## The family named and scheduled it between them

Bolaji proposed "a code boot camp for the kids."

> "Hackathon. Family hackathon."
> **Gbenga**, supplying the word that stuck

> "The Saturday of Easter, in between Good Friday and Sunday."
> **Grandma**, choosing the date, which Bolaji confirmed as 4 April

## Elsie solved a live production problem

When the quiz master handoff broke and Lina could not host, Elsie proposed that Bolaji keep hosting and share his screen while Middleton read the questions aloud.

> "That's a great idea, Elsie."
> **Bolaji**. It is what they did for the rest of the night.

She also proposed turning the game codes into a song so people would remember them.

## Why this matters

**Co-delivery is not a new idea. It is how Code Quest started.**

Before it had a name, Elsie and Hannah wrote the content, Arthur found the bug and was recruited to fix it, Lina volunteered to host, Gbenga named it, and Grandma set the date. Every one of them had already delivered part of Code Quest.

What followed was that Bolaji increasingly ran it alone. The ask for Code Quest 3 is therefore not a request for new help. It is a return to the original shape.

## Also on record

Elsie asked when the summer plans were happening. Gbenga said the family would come but might not manage the full itinerary. Bolaji: "I'm sure either way we'll do something cool." That summer visit became Code Quest 2.
