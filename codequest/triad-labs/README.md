## Adding your stuff

**Files go in `media/`.** Images, videos, anything.
Name them with dashes and no spaces: `race-sim-screenshot.png`, not `Race Sim Screenshot.png`.

**Then tell Uncle B** what each one is and where it should go, and it gets added to the page.
