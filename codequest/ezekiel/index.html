How to work on it

Four steps

1
Unzip it anywhere

No install, no setup, no build step.

2
Double-click index.html

That is the whole game. It opens in your browser and runs.

3
Open the same file in VS Code

It is free. The HTML, the styling and the code are all in that one file.

4
Change something, save, refresh

Small changes, refresh, check. If it breaks, press F12 and read the red text in Console — it tells you the line.

When you have a version you are happy with, send the file to Uncle B and it replaces the one online.
