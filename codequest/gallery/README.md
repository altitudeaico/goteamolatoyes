# Code Quest — photo gallery

Drop the Code Quest event photos into this folder (`codequest/gallery/`).

## Uploading via the GitHub website

1. Open **github.com/altitudeaico/goteamolatoyes/tree/main/codequest/gallery**
2. **Add file → Upload files**
3. Drag the photos into the drop zone
4. Leave **"Commit directly to the `main` branch"** selected → **Commit changes**

### Limits to know
- **25 MB per file** on web uploads — photos are fine; large `.MOV`/`.mp4` clips may be
  rejected (those need the terminal or Git LFS).
- **100 files per commit** — upload in batches if you have more.

> These pages are public (`altitudeaico.github.io/goteamolatoyes/codequest/`) and the
> event features children. Raw phone photos carry GPS location data — strip it before
> uploading if you'd rather not publish where the photos were taken.

Once the photos are in, tell Claude and it can build a gallery page that displays them.
